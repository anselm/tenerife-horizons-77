# Horizons ’77

A 32-page alternative-history magazine assembled at the close of an imagined Tenerife futures conference in 1977. Architecture, communal life, undersea habitats, cooperative finance, energy, and personal gliders raised by skyscraper lift stations. English, Spanish, French, Italian and German.

The complete issue is one continuous numbered sequence. Printed “see page…” references work quietly as links. Viewer controls sit outside the magazine paper. All articles, translations, atlas annotations and conference inserts appear in the reading flow.

## View locally

Open `index.html`, or serve this folder:

```sh
python3 -m http.server 8777 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8777`. No build, dependencies, accounts or external fonts are required.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**. The site uses relative asset paths and works as a project page. Pages hosting is not enabled by this commit.

The magazine and conference are fictional. Real luminaries appear as imagined contributors without fabricated authentic quotations or claims of historical attendance. The landscape is newly generated concept art; the maps and technical drawings are original graphics. See page 32 and `ART-DIRECTION.txt` for provenance.
