# Type for Horizons ’77

The URW families are unmodified digital revivals from [Artifex / URW base 35](https://github.com/ArtifexSoftware/urw-base35-fonts).
Bookman is used for display, Nimbus Roman for body copy, Nimbus Sans for labels,
and Nimbus Mono for occasional working-paper captions. These are digital
substitutes for older type traditions, not claims that the particular font
files existed in 1977. Georgia and Arial are no longer the edition’s chosen type.

See LICENSE and COPYING alongside the font files. The font license includes
an exception for embedding in PostScript and PDF documents. Original font
sources and related formats are available in the linked publisher repository.

The softer display cuts are derived from [Fraunces by Undercase Type](https://fraunces.undercase.xyz/),
under the included Fraunces-OFL.txt. Static settings: optical size 144,
softness 100, wonk 1; roman weight 750, italic weight 650. The derived files
are renamed Horizons Display; original author copyright is retained. Fraunces
is a contemporary design inspired by Cooper, Windsor and Souvenir, not a face
claimed to have been released in 1977. Bookman remains in quieter headings.
